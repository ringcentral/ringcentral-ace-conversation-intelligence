# Agent instructions

## Install or configure the plugin

When a user asks to install this plugin from the repository link, follow [INSTALL.md](INSTALL.md). It is the shared source for client commands, the `main` branch, update settings, RingCentral sign-in, and verification. Use the user's target app; complete supported installation steps and report any remaining user action.

## Change this repository

Follow [DEVELOPMENT.md](DEVELOPMENT.md). Preserve existing user changes, the agreed public display name, plugin ID `ringcentral-ace`, and client-specific package formats. Keep the root and packaged READMEs consistent. Run the documented checks appropriate to the change.

Keep installation instructions in `INSTALL.md`; link to them rather than duplicating the full guide in skills or other instruction files. Changing repository files does not install the plugin in a user's app. Commit, push, publish, and change account settings only within the user's requested scope.
