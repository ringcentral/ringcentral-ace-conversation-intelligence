# Security

Report suspected vulnerabilities privately through [RingCentral's vulnerability reporting process](https://www.ringcentral.com/trust-center/vulnerabilities.html). Include the affected plugin version and reproduction steps using synthetic data.

Use public GitHub issues for installation questions and general bugs. Keep credentials, customer interactions, and security-sensitive reproduction details out of public issues.

This repository distributes plugin instructions and connection configuration. RingCentral hosts the connected MCP service; plugin and service changes have separate release processes.
